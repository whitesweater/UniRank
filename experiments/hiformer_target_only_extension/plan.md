# HiFormer 仅历史汇聚接入 RISE：三个数据集扩展

日期：2026 年 9 月 24 日。

目标：检验 QK-Video 上有效的仅历史汇聚接入方式，是否也能改善 HiFormer 在 MerRec、KuaiRand、TencentGR 上的表现。仅新增三个 `target_only` 训练任务；QK-Video 使用已完成的位置对照，不重复训练。

最终报告范围为四个数据集：已有 QK-Video 任务 `644098_1` 与本轮三个扩展任务 `648217_0/1/2`。收集器逐项重审原始证据，`report.md` 和 `results/` 统一列出四项最终结果；四项报告范围不改变本轮仅提交三个新训练任务的事实。

唯一模型处理变化：保留历史 target attention 的完整 RISE，关闭三个字段交互层的 RISE。复用已经验证的接入位置控制；骨干模型、数据配置和既有冻结研究不改写。

## 比较与训练协议

| 数据集 | 完整 RISE 参考任务 | 完整 RISE 宏 AUC | 完整 RISE 宏 LogLoss |
| --- | --- | ---: | ---: |
| MerRec | 548166_2 | 0.80927640 | 0.08253240 |
| KuaiRand | 548166_6 | 0.86467100 | 0.17556467 |
| TencentGR | 548166_14 | 0.87085800 | 0.03029500 |

三个任务使用 seed 20262028、模型内 RISE 参数种子 20260822、数据加载种子 2027、2 张 H100、每卡 batch 16384、全局 batch 32768、1 epoch、最大历史长度 100；逐项从各自完整 RISE 的原始日志重建有效配置。保留 BF16、torch.compile、优化器和原有评测设置。运行 ID 使用新命名并保留独立检查点，不覆盖原始结果。

主要估计量是同一数据集内“仅历史汇聚减完整 RISE”的逐标签及宏平均 AUC/LogLoss 差值。宏指标是该数据集全部标签的等权平均。AUC 差值为正更好，LogLoss 差值为负更好。MerRec 和 KuaiRand 尚无对应 seed 20262028 的原生 Baseline；不把历史 seed 20262027 的原生结果当作本轮严格配对控制。TencentGR 已有额外的对应种子原生结果，可另列为辅助参照。

这属于已观察到 QK-Video 结果后的探索性扩展，每个数据集只训练一次，不能据此声称跨种子显著性。无论正负结果均保留，不将变体结果替换进原完整 RISE 主表。

## 验收与监控

提交前核查三个任务映射、保留参数和随机流、冻结配置与源码、CPU 回归及 Slurm shell 语法。运行中在两个 rank 分别验证只保留一个历史 RISE 接入点、三个字段接入均关闭，核对参数量与参数种子。

每 600 秒保存调度状态及审计快照。只有调度成功、双日志最终 Test 指标一致、配置与冻结清单一致、逐 rank 数据覆盖匹配参考、模型构造审计通过且检查点存在时，结果才计入完成表。提交、排队及运行中状态均不作为已完成实验。

提交回执保存在 `notes/submission.json`，审计结果保存在 `results/`，运行产物保存在 `artifacts/rise_hiformer_target_only_extension/`，最终独立比较写入本目录的 `report.md`。

并发要求：用户明确要求不限制并发。Slurm 使用 `--array=0-2`，不附加 `%N` 限制；三个任务各使用两张 GPU，由调度器分配资源并发执行。
