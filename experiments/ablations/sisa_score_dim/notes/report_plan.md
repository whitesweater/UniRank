## 报告结构映射

1. 标题与技术摘要：只有四个维度全部完成审计后才生成最终结论。
2. 范围、指标及比较口径：先解释每头维度、五标签等权宏平均和 16 维对照。
3. 宏平均发现：四行精确数值表、相对差值、64 维四卡布局差异的邻近说明。
4. 标签层面发现：分别展示完整 AUC、LogLoss 表，解释宏平均与个别标签的差异。
5. 实验设计和参数资源：固定训练协议、覆盖、参数量、实际任务身份与耗时。
6. 失败、重试及验证：保留 r64 两次 OOM、四次短诊断和最终四卡重试，解释状态去重修复。
7. 不确定性与结论边界：单种子、单组合、DDP 与样本保留差异、初始化和尺度混杂。
8. 推荐与后续问题：只在已有证据支持的范围内给结论，不自动扩充实验。
9. 归档位置：按用户要求整理全部记录，以普通代码路径列出可复现产物。

- 对照原始 checkpoint 和 Slurm 最终 Test，独立使用 Decimal 重算五标签宏平均。

- 报告中的全部表值、差值、排名和标签计数与保存证据独立核对。
- 使用 Markdown 结构检查确认无超链接、无缺失行、无待填内容。
