# SISA 组件消融实验报告：HyFormer–MerRec

结果快照：2026 年 9 月 17 日 14:19:22（北京时间）。

本报告仅展示 HyFormer–MerRec 的组件消融实验，包括三次新增训练与一次预先指定的历史完整 SISA 对照。四种配置均已完成并通过最终测试、有效配置及数据覆盖核验。所有数值来自最终测试集，本报告不汇总其他模型—数据集组合。

**主要结果：完整 SISA 取得最高宏平均 AUC（0.8008724）和最低宏平均 LogLoss（0.0826776）。相对仅内容打分，宏平均 AUC 提升 0.0177512；相对仅保留衰减或旋转的变体，分别进一步提升 0.0049924 和 0.0056422。这支持两个组件联合使用在本组合中的额外收益。宏指标最优不等于全部标签最优，逐任务差异在正文中完整保留。**

## 1. 实验目的与组件设计

SISA 在原有注意力 softmax 之前加入结构化分数偏置。该分支由内容投影、输入相关衰减、输入相关旋转和每头可学习缩放构成，原始 Q/K/V、已有掩码处理、残差及前馈结构保持不变。

本实验考察三个问题：衰减是否能改善仅内容打分；旋转是否能改善仅内容打分；联合使用两者是否优于各单组件变体。为此，采用以衰减、旋转为两个开关的 2×2 设计。

| 配置 | 名称 | 内容打分 | 动态衰减 | 动态旋转 |
| --- | --- | --- | --- | --- |
| B | content_only | 开启 | 关闭 | 关闭 |
| C | decay_only | 开启 | 开启 | 关闭 |
| D | rotation_only | 开启 | 关闭 | 开启 |
| E | full SISA | 开启 | 开启 | 开启 |

内容打分是衰减和旋转共同作用的基础，因此四种配置均保留该分支。B 用于衡量仅增加内容打分分支的表现，并不等同于原始骨干 baseline。C 是去掉旋转的完整模型，D 是去掉衰减的完整模型。

关闭衰减时令 log(alpha)=0，即 alpha=1；关闭旋转时令相位为零。未启用的分支被冻结且不参与前向计算，共同参数沿用相同初始化规则。所有配置保留相同的内容投影、每头可学习缩放及 SISA 接入位置。

B/C/D 均从头训练，不从 E 的 checkpoint 微调。E 复用实验启动前固定的 H100 完整 SISA 轮次，不根据消融结果更换对照。C−B、D−B 分别刻画单独加入衰减、旋转的收益；E−C、E−D 分别刻画已有另一组件时的增量贡献。

## 2. 数据集、任务与模型接入

MerRec 采用五任务二分类设置，标签为 Like、Cart、Offer、Checkout 和 Purchase。沿用已有 Parquet 分块数据及用户、物品侧表，不重新处理数据或改变标签定义。

数据按时间划分：训练集为 2023 年 10 月 1—25 日，验证集为 10 月 26—28 日，测试集为 10 月 29—31 日。已有预处理以每个 user–item 的首次 item_view 为样本锚点，将其后五类行为按 OR 合成为多标签；非 view 行为用于构造标签，不作为独立样本或历史 token。该流程沿用主实验，本次未重新审计逐事件标签归因窗口及跨划分边界情况。

所有配置保持相同的数据分块、排序、shuffle 和尾批处理规则。下表为两 rank 的完整 batch 合计保留的交互样本数，不是独立用户数，也不是预处理后全部行数。

| 划分 | 实际保留样本数 |
| --- | --- |
| 训练 | 144,048,128 |
| 验证 | 16,449,536 |
| 测试 | 11,599,872 |

训练、验证和测试均沿用按数据块丢弃不足一个 batch 尾部样本的规则。B/C/D 的逐 rank 块数、分配行数、batch 数和保留行数均与 E 匹配。历史数据未保存全量内容散列，覆盖一致本身不能证明样本内容逐字节一致。

HyFormer 使用三层骨干、两个注意力头、四个非序列 token 和两个 global token。SISA 接入三层序列自注意力及三层 query-to-sequence attention；四种配置使用完全相同的接入位置。本轮同时消融所有既有位置，不能进一步区分各位置的独立贡献。

## 3. 固定训练与评估协议

三个新增变体均匹配完整 SISA 在 seed 20262028 下的 H100 轮次。实际日志中允许变化的配置字段仅为 sisa_variant，以及用于区分输出的 model_id。原先其他 DDP 布局或种子的主实验基线不混入本轮组件差值。

| --- | --- |
| 硬件与并行 | 2×NVIDIA H100 80GB HBM3，DDP |
| 每卡 / 全局 batch | 16,384 / 32,768 |
| 梯度累积 / 训练预算 | 1 / 1 epoch |
| 最大历史长度 | 100 |
| 实验随机种子 | 20262028；各 rank 使用 seed＋rank |
| 数据加载随机种子 | 2027；epoch/rank 派生规则保持一致 |
| SISA 初始化种子 | 20260822；接入位置偏移保持一致，使用隔离随机数生成器 |
| Embedding / token 维度 | 16 / 256 |
| 骨干层数 / 注意力头数 | 3 / 2 |
| 非序列 token / global token 数 | 4 / 2 |
| 任务预测塔 | [128, 64]，ReLU |
| 稠密优化器 | AdamW，学习率 0.0001，weight decay=0 |
| 稀疏优化器 | Adagrad，学习率 0.05 |
| 稀疏优化器实现设置 | foreach=False，chunk_size=16,777,216 |
| 训练损失 | 各任务二元交叉熵先按 batch 求均值，再等权相加 |

| 数据加载 worker | 每 rank 4 个 |
| SISA 分数通道维度 | 16 |
| SISA 缩放初值 / score_scale | 0.1 / 1.0 |
| SISA 数值默认值 | decay_bias=−5，exp_clamp=11 |
| 验证与模型选择 | epoch 末同步验证，按验证集任务宏平均 AUC 选择 checkpoint |
| 正式测试 | 加载所选 checkpoint，汇集各 rank 预测后逐标签计算指标 |

项目使用 Python 3.12、PyTorch 2.8.0 及 CUDA 12.6 对应构建，依赖由项目锁文件管理。历史 E 缺少与本轮相同格式的完整源码及软件环境 manifest，因此不声称运行环境逐字节相同。score_dim、lambda_init 和 score_scale 由运行日志核对；decay_bias 和 exp_clamp 来自实现默认值。

主指标为 ROC-AUC，辅助指标为二元 LogLoss。每个标签先在汇集后的测试样本上计算指标，再对五个标签等权平均：Macro-AUC = (1/5)Σ AUC_k，Macro-LogLoss = (1/5)Σ LogLoss_k。AUC 越高越好，LogLoss 越低越好；标签不混池，差值均为绝对差值而非相对百分比。

## 4. 宏平均结果与组件贡献

完整 SISA 在四种配置中同时取得最好的宏平均 AUC 和 LogLoss。表中加粗表示数值最优，不表示统计显著；宏平均由原始日志六位小数的任务指标计算。

| 配置 | 宏平均 AUC ↑ | 宏平均 LogLoss ↓ |
| --- | --- | --- |
| B：仅内容打分 | 0.7831212 | 0.0858484 |
| C：内容打分＋衰减 | 0.7958800 | 0.0836942 |
| D：内容打分＋旋转 | 0.7952302 | 0.0834628 |
| E：完整 SISA | **0.8008724** | **0.0826776** |

| 对比 | ΔAUC ↑ | ΔLogLoss ↓ |
| --- | --- | --- |
| C−B | +0.0127588 | -0.0021542 |
| D−B | +0.0121090 | -0.0023856 |
| E−B | +0.0177512 | -0.0031708 |
| E−C | +0.0049924 | -0.0010166 |
| E−D | +0.0056422 | -0.0007852 |

**单独引入衰减或旋转均有效。** 相对 B，C、D 的宏平均 AUC 分别增加 0.0127588 和 0.0121090，五个任务的 AUC 均改善。这说明两种结构化变换分别能够改善内容分支的预测排序表现。

**联合使用两个组件带来额外收益。** E 相对 C、D 的宏平均 AUC 分别增加 0.0049924 和 0.0056422，宏平均 LogLoss 分别降低 0.0010166 和 0.0007852。以完整模型为参照，移除旋转或移除衰减均导致两项宏指标退化，支持两个组件在本组合、本种子下对完整模型的贡献。

**增量收益不等同于超加性协同。** AUC 的描述性交互量 I = E−C−D+B 为 −0.0071166，五个标签的交互量也均为负。完整模型相对 B 的增益小于两个单独增益之和，因此结果支持“组合进一步改善”，不足以支持“超加性协同”。负交互本身不等同于组件冲突或训练失败。

## 7. 可用于论文的表述

### 实验设置

为分析 SISA 中衰减和旋转机制的作用，本节报告 HyFormer–MerRec 上的四种组件配置：仅内容打分（B）、内容打分与衰减（C）、内容打分与旋转（D），以及完整 SISA（E）。各配置均保留相同的骨干、注意力接入位置、内容投影及每头可学习缩放，仅改变衰减和旋转的启用状态。B/C/D 均从头训练，E 复用预先指定的同协议完整模型。所有配置沿用相同的数据处理、划分和任务定义，采用两张 H100 GPU，每卡 batch size 为 16,384，全局 batch size 为 32,768，训练一个 epoch，最大历史长度设为 100。实验种子为 20262028，并匹配数据加载及 SISA 初始化子种子。稠密参数采用 AdamW，学习率为 10⁻⁴；稀疏参数采用 Adagrad，学习率为 0.05。模型按验证集任务宏平均 AUC 选择，并在测试集上报告五个任务的 AUC、LogLoss 及其等权宏平均。

### 结果分析

在 HyFormer–MerRec 上，完整 SISA 取得最高宏平均 AUC 0.8008724 和最低宏平均 LogLoss 0.0826776。相对仅内容打分，单独引入衰减和旋转的宏平均 AUC 分别提高 0.0127588 和 0.0121090，完整模型提高 0.0177512。与仅保留衰减或旋转的配置相比，完整模型的宏平均 AUC 分别进一步提高 0.0049924 和 0.0056422，宏平均 LogLoss 分别降低 0.0010166 和 0.0007852。这表明在该组合及本次训练条件下，两种机制分别有效，联合使用能够进一步改善整体预测表现。不过，Offer 任务的最高 AUC 来自仅旋转变体，部分任务的 LogLoss 也未随宏平均同步改善，因此整体优势不等同于逐任务全面最优。

### 解释边界

本节仅报告一个模型—数据集组合和一个实验种子，不用于概括全部实验场景，也不报告统计显著性。各变体的有效参数量并非完全相同；此外，AUC 的描述性交互量为负，因此结果不支持超加性协同或对组件普遍必要性的判断。

## 8. 局限与后续验证

当前结果支持 HyFormer–MerRec 上两个组件的单独贡献和联合使用的宏指标收益。其余问题仍需独立证据：单种子无法估计增益的训练随机性；有效参数量不完全匹配，无法完全排除容量因素；没有固定衰减或固定旋转对照，无法单独证明输入自适应优于固定规则；没有分接入位置消融，无法定位收益主要来自哪类注意力；没有受控的延迟、吞吐或显存实验，不能据此推断效率优势。

如需加强论文结论，后续应预先固定比较方案，在相同设置下补充配对种子的重复实验，再评估增益的稳定性。对 MerRec 数据说明，还应核实标签归因窗口及是否跨越划分边界。本报告展示范围限定为 HyFormer–MerRec，保留该范围内全部标签和两项指标，以便读者同时判断整体收益与逐任务差异。
