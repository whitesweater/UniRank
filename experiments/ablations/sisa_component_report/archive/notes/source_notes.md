## 指标定义与检查

- 指标粒度为模型—数据集—变体—种子—标签；每个变体仅一个种子。
- 宏指标是组合内标签等权均值，不是跨种子均值，也不是标签混池指标。
- 差值采用日志六位小数计算，原始值及衍生表同时保留，不从显示后的均值反算。
- C−B、D−B、E−B、E−C、E−D 及 E−C−D+B 均保存逐标签和宏结果。
- 采集器只对 B/C/D/E 全部合格的组合生成比较；当前三组均满足条件。
- 正文生成器再次从逐标签值重算均值，并检查已审阅的主要结论仍符合指标。
- 原始指标、宏指标及差值经过独立 Decimal 算术交叉检查，浮点差异低于 1e−14。
- 可训练参数仅统计 requires_grad=True，B 中的冻结组件不被当作容量控制。

数据日期与预处理说明来自原有主实验报告和其数据审计；本轮没有重跑预处理。
损失的等权求和、参数量统计规则及 SISA 默认数值由当前实现再次核对。
当前运行配置核对通过，历史 E 缺少同格式全源码及软件环境 manifest；报告已保留边界。

## 保留的不确定性

RankMixer 的 C 在两项宏指标上优于 E；HyFormer 的 E 宏指标最好但部分标签指标退化。
HiFormer 的 E 宏 AUC 最高（0.870858），D 宏 LogLoss 最低（0.029010）；E 相对 D
的宏 AUC 提升 0.008726，同时宏 LogLoss 增加 0.001285，两个标签的 LogLoss 均退化。
三组中完整 SISA 并非始终同时最优，排序与概率损失的变化方向也不总是一致。

RankMixer 与 HyFormer 的宏 AUC 交互量 E−C−D+B 分别为 −0.007317 和 −0.0071166；
HiFormer 为 +0.002526。因此可以描述 HiFormer 该次运行的正交互，不能把它推广为
全部场景存在超加性协同。只有一个 seed、按已知收益选组、
没有固定规则控制或等有效参数控制，也没有新的同 seed 原始骨干 A。
因此正文不主张统计显著、跨种子稳定、所有场景两组件必要或效率优势。

单元测试覆盖验证集污染、重复/缺失/非有限指标、错误变体与 seed、未完成任务、
数据覆盖不匹配以及双日志不一致。本次刷新后重新执行完整 CPU unittest 回归，
108 项全部通过；104 个原始指标对应的宏均值及 96 条比较记录也经独立 Decimal
重算核对，误差低于 1e−14。正文通过独立科学结论与数字审阅，验证输出保存在 Git 忽略的
