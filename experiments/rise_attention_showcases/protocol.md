# 可读、说明性的真实案例筛选

2026-09-24。范围仍为原有四数据集，本轮沿用已验证RankMixer–KuaiRand的512条固定诊断交互，不新增训练。

用户明确允许近期或局部展示，并希望尝试不同类型的有意义案例。因此不再把“解释整体收益至少一半”作为每张局部图的要求；但不得把无效、反向或仅共现的结果写成机制因果证明。

本轮探索了：近期窗口内排序翻转、旧主题与近期内容差异、同一候选过去出现过且具有正/负反馈等情形。扫描和所有文字可用性记录保留于artifacts/rise_attention_case_search/recent_window_scan。
筛选使用了已有模型结果和观察标签，属于有目的的说明性选例，不代表总体分布。

本次固定以下三个真实候选，在新干预结果出现前不再更换：

1. sample155：同一视频在第96位置已被点击；当前再次出现且实际点击。展示同内容的正反馈历史是否参与预测改善。
2. sample416：同一游戏视频在第97位置仅曝光；当前再次出现且未点击。展示attention增加也可能加强负向证据，而非必然表示喜欢。
3. sample24：候选是铜锣烧，较早的手抓饼早餐历史已点击并长看，较新的剧情片段仅曝光。此相邻局部由原先剧情权重更高变为早餐权重更高；展示一个不符合单纯位置单调性的排序变化。

G/C位置见groups.json。仍复用全序列softmax和已验证组质量回退/共同接收集合等剂量对照/平均位置模板。图示局部不重新归一化为原权重；展示范围和其余质量必须说明。

候选对应的历史事实已从同源caption/cover、ID和duration核验；标题可忠实摘要，完整原文另存。原始反馈及是否同一item均在源数组上验证，不靠标题相似猜测。

先核验单组增权回退是否使该样本真实标签的BCE恶化。若没有，不把该条历史作为收益来源来讲。局部attention排序图与预测归因图分开定位，不用整体预测改善去替代该局部作用的验证。
不将低于0.5的点击概率叫作错误或正确，不把单样本损失方向当成总体AUC或校准结论。

更清楚且数值对比明显者作为主展示；无文字、含混内容、反向效果均列入未采用记录。不得为了漂亮而编造标题、删除影响结论的同窗口记录，或隐瞒位置模板几乎复现收益的事实。
