# 两个更容易读懂的真实案例

日期：2026-09-24。使用原有KuaiRand数据及已有RankMixer–RISE检查点，seed 20262028。本文给出两个不同用途的说明性案例：一例解释负向历史证据，一例展示相邻位置的attention排序翻转。

两例都是从已验证诊断数据中有目的地筛选的真实交互，不代表总体分布；文案来自同一KuaiRand的官方注释。图形局部放大始终保留完整100条历史下的原权重。

## 1. 推荐主例：更高attention，也可以是在利用负向证据

**直观故事：同一条游戏视频此前曝光过但没有被点击，再次出现时仍没有被点击。RISE增加此前这条记录的权重，同时降低本次点击预测；回退这条记录的权重会把预测推回较不利的方向。**

此处是完全相同的video ID，不是仅凭标题相近来认定相关。

| 内容与反馈 | 已核实事实 |
|---|---|
| 当前候选 | 《逃跑吧少年》西游记联动主题视频；标题按官方话题标签概述 |
| 历史证据 | 位置97，和候选为同一视频，encoded item_id=3954595 |
| 历史反馈 | exposure，没有记录点击 |
| 本次真实反馈 | 没有点击，y=0 |
| 这条历史的attention | 0.9926%→5.3307% |

| 对照 | p(click) | 该未点击标签的BCE |
|---|---:|---:|
| 该处RISE修正关闭 | 64.8438% | 1.045368 |
| RISE完整修正 | 55.8594% | 0.817790 |
| 仅把这条历史的总权重退回原水平 | 59.3750% | 0.900787 |

RISE整体将点击概率降低8.9844个百分点，使该未点击标签下的BCE下降。局部回退后，概率回升3.5156个百分点、BCE升高0.082997，支持这条历史的增权参与了本例改善。

相同移动质量的近邻对照为位置98的另一款游戏视频，其记录为点击、长观看。回退该近邻的相同质量后，p(click)=54.6875%，没有出现回退原先未点击视频时的损害。两条记录的内容、反馈均不同，因此这是两条历史的局部作用对照，不单独隔离“点击标记”或“相同物品ID”的贡献。

**这张图最适合解释：attention是证据的聚合权重，不能直接当作喜欢程度。** 在本例中，被增权的已有未点击记录支持的是降低当前点击倾向。

必须保留的范围：预测仍高于0.5，本例没有实现阈值分类翻转，不写成“成功判定不点击”或“拒绝推荐”；仅说明概率与BCE向真实未点击标签改善。未点击也不等于现实用户表达了厌恶。等幅平均位置模板的预测为56.2500%，已接近full，因此本例不证明超越一般近期性或AM/PA各自必要。

主图：`figures/negative_evidence_416.pdf`，同时提供同名PNG和SVG。

## 2. 局部放大例：较早的早餐条目超过更新的剧情条目

候选文案为“铜锣烧、日本美食”，真实反馈是点击。只放大相邻位置94和95，内容关系与反馈都很容易阅读。

| 历史 | 位置 | 记录反馈 | 修正前attention | 等幅平均位置模板 | RISE实际attention |
|---|---:|---|---:|---:|---:|
| 3分钟手抓饼早餐做法 | 94，较早 | 点击、长观看 | 0.9166% | 3.4696% | **3.7760%** |
| 《反转人生》剧情片段 | 95，更新 | 仅曝光 | **1.0498%** | **4.5027%** | 3.6416% |

原生分数以及等幅平均位置模板都使更新的剧情条目权重更高。RISE的实际修正使较早的早餐条目超过剧情条目：其Delta分别为2.250000和2.078125，较早条目得到更大的相对分数修正。

这给出一个清楚的局部事实：实际修正没有简单照搬这个平均位置模板的排序。由于早餐与剧情在内容和历史反馈两方面都不同，不能仅凭这两个位置进一步识别究竟是哪一种输入特征导致了区别。

该样本整体p(click)从43.9453%提高到48.2422%，BCE从0.822224降低到0.728936。只把早餐条目权重退回后，p(click)=48.0469%，说明这一个条目的独立回退效果较小。**因此，这张图用于展示局部排序的可读变化，不拿它解释整例全部预测增益。**

主图：`figures/local_order_24.pdf`，同时提供同名PNG和SVG。

## 3. 选例与未采用的候选

本轮没有再限定必须寻找远距离历史。筛选覆盖了近期窗口的相对份额、较早条目超过更新条目的排序、同一内容的重复曝光、以及真实未点击样本的改善。

primary_tag只用于初筛，最终内容关系通过官方caption/cover核对。例如，sample414虽然同属“游戏”大类，但候选是《光遇》，历史是《王者荣耀》，没有被包装成同款游戏的相关性案例；sample299缺少候选文案而被排除。

一个表面上很醒目的正例sample155，整体点击概率从16.70%升到37.11%，且历史里有同一视频的点击记录。但回退那一条历史只使概率降至36.52%，近邻对照影响还更大。因此没有把这20个百分点提升归给该单条历史，也没有把它作为主展示。

最终两例来自原512条交互，只执行了新的固定局部干预，没有新增数据集或训练。所有筛选、缺失文字、核验失败和未采用候选记录均保存在 `artifacts/rise_attention_case_search/recent_window_scan/`。

## 4. 对照与验证

“关闭修正”始终指同一个已训练模型在该target-attention位置关闭score bias，不是独立训练的Baseline。组质量回退保留该组在full中的条件分布，使用完整允许键集合重新归一化。所有输入、Q/K/V和其余模型参数保持固定。

| 核验 | 结果 |
|---|---|
| 新推理作业 | 646610，完成并退出0:0 |
| 原预测、零调整hook、Q/K/V、非probe行 | 严格一致性门槛全部通过 |
| source哈希、实际softmax、BCE和标签 | 独立审计通过，结果见results |
| 原始文案与物品身份 | 精确ID、两个重叠Range、duration_bucket核验通过 |
| 展示方式 | 位置94—95只作局部放大，原权重不重新归一化 |
| 图形 | PNG实际检视，PDF/SVG同时导出 |

回退结果是固定模型内的计算干预；单条干预效果不是可相加的收益分解，也不证明人的真实兴趣或总体排序性能。

## 5. 可用于论文的短说明

**负向证据案例：**

> 该候选视频在历史中曾被曝光但未点击，本次再次曝光仍未点击。RISE将该历史记录的attention由0.99%提高至5.33%，同时将点击预测由64.84%降低至55.86%。仅回退这条历史的总权重，预测回升至59.38%，说明这条记录的增权参与了该未点击样本的预测改善。这也体现了attention的证据聚合作用：更高权重不必对应更高的点击倾向。

**局部排序案例：**

> 对铜锣烧候选，较早的早餐历史已被点击并长观看，邻近更新的剧情历史仅曝光。修正前及等幅平均位置模板均给予剧情条目更高权重，RISE实际修正则将局部排序翻转为早餐条目更高。该例展示一个可读的局部排序变化；其单条回退的预测作用较小，不用于解释整例全部增益。
